# АйтиШторм - сайт digital-агентства

## О проекте

АйтиШторм - веб-приложение digital-агентства, предоставляющего услуги по созданию сайтов, продвижению бизнеса, рекламе и копирайтингу.

Проект представляет собой полноценное приложение с клиентской и серверной частями. Помимо презентации услуг агентства, сайт включает блог с системой публикации комментариев, пользовательской регистрацией и авторизацией. Для хранения данных используется MongoDB, а взаимодействие между frontend и backend реализовано через REST API.

## Функциональность

- **Главная страница:** презентация агентства, информация об услугах, преимуществах и отзывах клиентов.
- **Слайдер акций:** отображение специальных предложений и новостей с возможностью переключения слайдов.
- **Каталог услуг:** карточки услуг по созданию сайтов, продвижению, рекламе и копирайтингу с описанием и стоимостью.
- **Заявки на услуги:** отправка заявок с указанием имени, телефона и выбранной услуги.
- **Заказ консультации:** форма обратной связи для получения бесплатной консультации.
- **Блог:** просмотр публикаций и популярных статей агентства.
- **Фильтрация статей:** отбор публикаций по категориям с возможностью комбинировать фильтры.
- **Пагинация:** постраничная навигация по списку статей.
- **Страница статьи:** просмотр полного текста публикации и связанных материалов.
- **Комментарии:** просмотр комментариев, публикация новых сообщений и загрузка дополнительных комментариев.
- **Реакции на комментарии:** возможность ставить лайки и дизлайки, а также отправлять жалобы на комментарии.
- **Регистрация и авторизация:** создание аккаунта и вход с использованием электронной почты и пароля.
- **Управление авторизацией:** автоматическое обновление токенов доступа при истечении срока действия.

## Особенности реализации

**Frontend:**
- Компонентная архитектура с разделением приложения на функциональные и общие модули.
- Использование Angular Router и ленивой загрузки модулей для организации маршрутизации.
- Создание сервисов для получения статей и категорий, отправки заявок, работы с комментариями и авторизацией.
- Использование RxJS и Observable для обработки асинхронных операций.
- Реализация HTTP-интерцептора для добавления токена авторизации к запросам и обновления токенов при получении ошибки 401.
- Использование Guards для управления доступом к маршрутам.
- Создание реактивных форм с помощью FormBuilder, FormGroup и встроенных валидаторов Angular.
- Использование Angular Material для диалоговых окон, уведомлений и элементов интерфейса.

**Backend:**
- Разработка REST API на Express.js.
- Организация серверной логики с использованием контроллеров, моделей и маршрутов.
- Работа с MongoDB через Mongoose.
- Реализация регистрации, авторизации и выхода из аккаунта с использованием JWT и refresh-токенов.
- Хеширование пользовательских паролей с помощью bcrypt.
- Проверка и валидация входящих данных с использованием Joi.
- Реализация системы комментариев и пользовательских реакций на них.

## Запуск проекта

Для локального запуска потребуются:
- Node.js и npm.
- Установленная и запущенная MongoDB.

### 1. Клонирование репозитория

```bash
git clone https://github.com/Kryanrd/web-studio-angular.git
cd web-studio-angular
```

### 2. Настройка базы данных

Запустите MongoDB.

Backend использует локальное подключение:

`mongodb://127.0.0.1:27017`

Название базы данных:

`diploma`

Настройки подключения находятся в `backend/src/config/config.js`.

Для заполнения базы данными предусмотрен инструмент миграций migrate-mongo. При наличии файлов миграций выполните их применение из папки `backend`:

```bash
npx migrate-mongo up
```

### 3. Запуск Backend

Откройте первый терминал и перейдите в папку `backend`:

```bash
cd backend
```

Установите зависимости:

```bash
npm install
```

Запустите сервер:

```bash
npm start
```

Backend будет доступен по адресу:

`http://localhost:3000`

### 4. Запуск Frontend

Откройте второй терминал и перейдите в папку `frontend`:

```bash
cd frontend
```

Установите зависимости:

```bash
npm install
```

Запустите приложение:

```bash
npm start
```

Frontend будет доступен по адресу:

`http://localhost:4200`

Для корректной работы приложения необходимо одновременно запустить MongoDB, Backend и Frontend.

## Сборка проекта

Для создания production-сборки frontend выполните команду из папки `frontend`:

```bash
npm run build
```

Собранные файлы приложения будут размещены в папке `dist/frontend/`.
